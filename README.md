# 🎓 Calculadora de Média Escolar (JavaScript)

> Uma aplicação web prática e funcional desenvolvida para auxiliar estudantes e professores a calcular médias escolares de forma rápida, fornecendo o status final de aprovação do aluno.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na consolidação de conceitos fundamentais de **JavaScript moderno (ES6+)**, como operadores aritméticos, estruturas condicionais (`if/else`), validação de formulários e manipulação do DOM para exibição dinâmica dos resultados.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica da página e formulários para inserção de notas.
* **CSS3:** Estilização visual, organização de elementos e layout responsivo.
* **JavaScript (ES6+):** Lógica matemática para cálculo da média, validação das notas e alteração dinâmica da interface.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Cálculo da Média:** Processa as notas inseridas e calcula a média aritmética final.
* **Status de Desempenho:** Exibe automaticamente se o aluno foi **Aprovado**, ficou em **Recuperação** ou foi **Reprovado**.
* **Validação de Entradas:** Impede o envio de campos vazios ou valores de notas fora da escala permitida.
* **Interface Limpa e Responsiva:** Adaptada para navegação intuitiva em computadores e dispositivos móveis.
